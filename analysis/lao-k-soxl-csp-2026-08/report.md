### 歷史路徑機率模型核對

Screener 新增的 probability engine 使用 SOXL 前復權（QFQ）日線，對相同交易天數的 rolling paths 計算：（1）到期收盤低於 strike 的比例；（2）期間最低價觸及 strike 的比例。逐日只使用推薦日當時以前的資料回測 24 筆截圖後，`Expiry ITM Probability` 的平均絕對誤差（MAE）為 **0.37 個百分點**，`Touch Probability` 的 MAE 為 **0.87 個百分點**；這表示獨立重建已非常接近截圖模型，但不宣稱兩者公式完全相同。

### 最可能的選股流程（約 80%–90% 信心）

1. 把可用週到期日分成 1–5 週 bucket，每個 bucket 最多選 1 張。
2. 套用第一道硬風險門檻：**到期 ITM probability ≤5.0%**；不合格就空缺，不為了「每日五選」硬湊。
3. 第二道收益門檻較可能是 **midpoint／理論 annualized yield ≥20%**；bid 年化是保守的 executable yield 顯示值，但不是硬淘汰條件。
4. 用 **Delta -0.10 至 -0.02、OTM 20%–45%** 作安全護欄。24 筆自然集中在 Delta **-0.036 至 -0.087**、OTM **22.4%–40.3%**、touch probability **5.9%–13.9%**。
5. 開倉紀錄使用 midpoint，而「實收年化」使用 bid。這是合理的風險展示方式，但 midpoint 不應被視為保證成交價。
6. 每天對不同 expiry 加 1 口，舊部位不被新推薦取代，形成跨到期日與履約價的 tranche ladder（分批梯形持倉）。七天推薦數依序為 4、4、3、3、2、4、4，完全反映有幾個 bucket 通過門檻。

### 仍不能從五日樣本確定的規則

- exact liquidity gate（最低 OI、volume、最大 spread）無法確定。特別是 8/28 的 78P spread 為 `1.05 / 3.40`，非常寬，說明 liquidity 並非嚴格到足以排除異常報價。

- 持倉頁只標記「浮盈 ≥80%」筆數，沒有平倉成交，因此不能把 80% 當成已證實的 exit rule。

## 4. Premium 與績效的正確解讀

### Midpoint tracker 口徑

- Opening premium：**`$2,092`**。
- Current buyback liability：**`$1,353`**。
- Gross unrealized P&L：**`$739`**。
- Weighted premium capture：`739 / 2,092 = 35.3%`。
- Unrealized return on strike collateral：`739 / 119,500 = 0.62%`。
- Opening premium / collateral：`2,092 / 119,500 = 1.75%`。
- 依 collateral-days 簡單年化的 opening premium pace：約 **32.0%**；這不是帳戶預期年報酬，未計 idle cash、滑價、佣金、assignment loss 與 tail risk。

### 為什麼頁首是 +40.7%

逐筆顯示報酬率的簡單平均是 **40.6625%**，四捨五入後剛好等於頁首 **+40.7%**。這種算法讓 `$15` premium 的小部位與 `$223` premium 的大部位權重相同，因此不能當成 portfolio return。

### 實際可成交 Premium 可能較低

現在五天、16 筆推薦的 bid/mid/ask 已完整：

- 推薦 midpoint opening premium：**`$2,157`**。
- 同時點 bid-based executable premium：**`$1,807`**。
- Bid 為 midpoint 的 **83.8%**，即 midpoint 比立即可成交 bid 高 `$350`／19.4%。
- Tracker 持倉 midpoint premium：**`$2,092`**；因為兩筆 contract 與兩筆盤中價格不同，不能直接等同於 `$2,157` 的推薦組合。
- 最大的 distortion 仍是 8/28 78P，其 bid/mid/ask 為 `1.05 / 2.23 / 3.40`；單筆 midpoint 就比 bid 多 `$118`。

所以 `$2,092` 應視為 tracker fair-value credit，而不是實收現金。若實際依五日推薦在畫面時點直接 hit bid，最具證據支持的 gross premium benchmark 是約 **`$1,807`**，而不是先前只能以抽樣推算的 `$1,600–$1,900` 區間。真正實收仍須以 broker fills 為準。

## 6. 風險判讀

- 低 Delta 不等於低 portfolio risk。16 口全部集中 SOXL，若半導體急跌，put Delta、gamma 與 IV 會同時上升，`$8.8k` current dollar-delta 可迅速靠近更大的 assignment exposure。
- 使用 midpoint 會高估可成交收益，寬 spread 合約尤其明顯。策略評估應以 sell bid 或實際 fill 為主，midpoint 只能作 fair-value mark。
- 「到期 ITM 機率 5%」不是實際 loss probability。入選合約的提前觸及機率仍為 **5.9%–12.8%**，而且 3× ETF 的跳空、volatility clustering 與路徑依賴可能使簡化模型低估尾部風險。
- `$119,500` 是 cash-secured funding requirement，不應被低至 `$8.8k` 的當下 dollar-delta 掩蓋。
- 目前樣本沒有 losers、assignments、rolls 或 realized exits，不能估 win rate、expectancy、最大回撤或真實年化報酬。

2. 同一天不同時間的推薦頁，可確認 8/25 差異是否來自盤中動態重算。
3. 第一批 close／roll／assignment 截圖，可辨識是否真以 80%、90% 或到期歸零為 exit rule。
4. 至少一個完整月、包含未推薦與虧損案例的資料，才能估計 selection bias、MAE、assignment rate 與 portfolio drawdown。
